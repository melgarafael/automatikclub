Ativando o OpenClaw na VPS

12 min de leitura Nivel: Iniciante

Sua VPS HostGator ja vem com o OpenClaw pre-instalado. Nesta aula voce vai acessar o servidor, verificar que tudo esta rodando e fazer a ativacao inicial. Em poucos minutos seu agente estara no ar, pronto para ser configurado.

Vantagem do plano VPS OpenClaw

Como a HostGator ja entrega a VPS com o OpenClaw configurado, voce nao precisa instalar Node.js, dependencias ou rodar scripts. O ambiente ja esta pronto — basta ativar.

Acessando sua VPS

Use as credenciais que recebeu por email da HostGator. Abra o Terminal (Mac/Linux) ou o PowerShell (Windows) e conecte via SSH:

# Substitua SEU_IP_AQUI pelo IP que recebeu no email de ativacao ssh root@SEU_IP_AQUI

Na primeira conexao, o terminal vai perguntar se voce confia no servidor. Digite yes e pressione Enter. Depois, digite a senha que recebeu por email.

Dica

No Windows, se o comando ssh nao funcionar, baixe e instale o PuTTY (putty.org) — e um cliente SSH gratuito.

Verificando que o OpenClaw esta Rodando

Como a VPS ja vem com OpenClaw, o primeiro passo e confirmar que o servico esta ativo:

# Verifica o status do OpenClaw openclaw status

Voce deve ver uma mensagem confirmando que o servico esta ativo e rodando. Se aparecer algum erro, veja a aula M2A6 (Troubleshooting).

Acessando o Painel do OpenClaw

O OpenClaw tem uma interface web para configuracao. Acesse pelo navegador:

# Abra no navegador (substitua pelo IP da sua VPS) http://SEU_IP_AQUI:3000

Clonando e Instalando OpenClaw

1

Clonar o repositorio

Baixe o codigo-fonte do OpenClaw direto do GitHub:

git clone https://github.com/openclaw/openclaw.git
2

Entrar na pasta do projeto

Navegue ate o diretorio que foi criado:

cd openclaw
3

Instalar as dependencias do projeto

O npm vai baixar e instalar tudo que o OpenClaw precisa:

npm install
4

Criar o arquivo de configuracao

Copie o arquivo de exemplo para criar seu .env personalizado:

cp .env.example .env
5

Executar o setup inicial

O comando de setup configura o banco de dados e prepara o sistema:

npm run setup
Dica

Se o npm install travar ou der erro de dependencia, rode npm install --legacy-peer-deps. Isso resolve conflitos de versao entre pacotes.

Verificando a Instalacao

Para confirmar que tudo esta funcionando, rode o comando de verificacao:

npm run status # Saida esperada: # ================================ # OpenClaw Status Check # ================================ # Node.js: OK (v18.17.0) # Database: OK (connected) # Config: OK (.env loaded) # Dependencies: OK (all installed) # ================================ # Status: READY # ================================
Tudo certo!

Se todos os itens mostraram OK, seu OpenClaw esta instalado e pronto. Na proxima aula vamos conectar a inteligencia artificial que dara ao agente capacidade de raciocinio e tomada de decisao.

Atencao

Nunca execute comandos como root em producao. Depois que tudo estiver funcionando, crie um usuario dedicado (veremos isso na aula 5). Por enquanto, root esta OK para o setup inicial.
