Liberando Acesso Total

20 min de leitura Nivel: Intermediario

Ate agora seu agente so funciona quando voce acessa diretamente pelo servidor (localhost). Para que o OpenClaw possa operar processos reais — acessar APIs externas, conectar em bancos de dados, receber tarefas de outros sistemas — voce precisa liberar o acesso de rede com seguranca.

Configuracoes de Rede

O primeiro passo e configurar o firewall para permitir que o agente se comunique com o mundo exterior e receba tarefas de sistemas externos. O Ubuntu usa o UFW (Uncomplicated Firewall):

1

Habilitar o firewall

Ative o UFW se ainda nao estiver ativo:

# Habilita o firewall sudo ufw enable # Primeiro, garanta que SSH continua acessivel! sudo ufw allow 22/tcp
2

Liberar a porta do OpenClaw

Abra a porta 3000 (onde o agente recebe tarefas) para conexoes externas — permitindo que outros sistemas deleguem processos ao agente:

# Libera a porta do OpenClaw sudo ufw allow 3000/tcp
3

Liberar portas HTTP e HTTPS

Essenciais para o agente acessar APIs externas, servicos de pagamento, bancos de dados remotos e para configurar o dominio com SSL:

# Libera HTTP e HTTPS sudo ufw allow 80/tcp sudo ufw allow 443/tcp
4

Verificar as regras

Confirme que todas as regras estao corretas:

sudo ufw status # Saida esperada: # Status: active # To Action From # -- ------ ---- # 22/tcp ALLOW Anywhere # 3000/tcp ALLOW Anywhere # 80/tcp ALLOW Anywhere # 443/tcp ALLOW Anywhere
Atencao

Nunca exponha a porta do admin sem autenticacao configurada. Um agente executor tem acesso a operacoes sensiveis — proteja-o. Sempre libere a porta SSH (22) antes de ativar o firewall, senao voce perde acesso ao servidor!

Configurando Dominio (Opcional)

Um dominio proprio (ex: agente.suaempresa.com.br) passa mais profissionalismo. Veja como configurar:

1

Registrar ou usar um dominio existente

Se ainda nao tem, registre um dominio em registro.br (dominios .com.br) ou Namecheap (dominios internacionais). Se ja tem, pule para o proximo passo.

2

Configurar o registro DNS tipo A

No painel do seu provedor de dominio, crie um registro A apontando para o IP da sua VPS:

# Exemplo de configuracao DNS: Tipo: A Nome: agente # ou @ para o dominio raiz Valor: SEU_IP_DA_VPS TTL: 3600
3

Aguardar a propagacao

A propagacao DNS pode levar de 5 minutos a 48 horas (geralmente menos de 1 hora). Teste com:

ping agente.seudominio.com.br
Dica

Use um dominio proprio — facilita a integracao com outros sistemas e passa mais profissionalismo. "agente.suaempresa.com.br/api/task" e muito melhor que "123.456.789.0:3000/api/task".

SSL com Let's Encrypt

SSL (o cadeado verde) e obrigatorio quando o agente executa operacoes sensiveis — cobrancas, acesso a dados financeiros, processamento de informacoes pessoais. O Let's Encrypt oferece certificados gratuitos:

# Instalar o Certbot sudo apt install -y certbot # Instalar o plugin para Nginx (servidor web) sudo apt install -y python3-certbot-nginx # Gerar o certificado SSL (substitua pelo seu dominio) sudo certbot --nginx -d agente.seudominio.com.br # O certbot vai pedir seu email e aceitar os termos # Depois, configura automaticamente o SSL no Nginx

O certificado e renovado automaticamente. Para verificar, rode:

# Testar renovacao automatica sudo certbot renew --dry-run

Permissoes de Usuario e Delegacao de Tarefas

Rodar tudo como root e um risco de seguranca — especialmente com um agente que executa processos autonomamente. Crie um usuario dedicado com permissoes controladas:

# Criar usuario dedicado sudo adduser openclaw # Dar permissoes necessarias sudo usermod -aG sudo openclaw # Mover o projeto para o usuario sudo cp -r /root/openclaw /home/openclaw/ sudo chown -R openclaw:openclaw /home/openclaw/openclaw # Trocar para o novo usuario su - openclaw # Verificar cd ~/openclaw && npm run status

Acessando de Qualquer Lugar

Agora teste o acesso externo. Do seu computador pessoal (nao do servidor), abra o terminal e envie uma tarefa remotamente:

# Se configurou dominio: curl https://agente.seudominio.com.br/api/task \ -X POST \ -H "Content-Type: application/json" \ -d '{"task": "Retornar o status atual do servidor: uptime, memoria e disco"}' # Se esta usando IP direto: curl http://SEU_IP:3000/api/task \ -X POST \ -H "Content-Type: application/json" \ -d '{"task": "Retornar o status atual do servidor: uptime, memoria e disco"}'
Sucesso!

Se recebeu o resultado da tarefa, seu agente esta acessivel de qualquer lugar do mundo. Qualquer sistema, aplicativo ou webhook pode delegar tarefas a ele agora — de cobrancas automaticas a relatorios sob demanda.
