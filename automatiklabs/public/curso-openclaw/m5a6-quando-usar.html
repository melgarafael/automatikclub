Cron vs Heartbeat vs Skill Manual: A Arvore de Decisao

🕑 20 minutos 🎯 Estrategico

A Arvore de Decisao

Voce agora tem tres mecanismos de execucao. A pergunta e: para cada processo do negocio, qual usar? Siga esta arvore:

1

O processo precisa rodar em um horario fixo ou intervalo regular?

SIM → Cron. Relatorio toda segunda as 8h. Cobranca todo dia 5. Backup as 3h. O gatilho e o relogio.

NAO → Proximo passo.

2

O processo precisa reagir a um evento que pode acontecer a qualquer momento?

SIM → Heartbeat. Estoque abaixou. Pagamento atrasou. Erro no sistema. O gatilho e um evento do negocio.

NAO → Proximo passo.

3

O processo so faz sentido quando alguem pede explicitamente?

SIM → Skill Manual. Gerar contrato sob demanda. Calcular comissoes quando o vendedor pede. Consultar status de pedido. O gatilho e uma pessoa.

Regra de Ouro

Cron = gatilho e o relogio. Heartbeat = gatilho e um evento. Skill Manual = gatilho e uma pessoa. Se voce lembrar dessas tres frases, vai acertar 95% das vezes.

Matriz de Decisao com Cenarios Reais

Processo Ferramenta Por Que
Gerar relatorio de vendas toda segunda Cron Horario fixo, previsivel
Processar cobrancas dia 5 de cada mes Cron Data fixa no calendario
Reagir quando estoque ficar abaixo do minimo Heartbeat Evento imprevisivel, reacao imediata
Disparar cobranca quando pagamento atrasar Heartbeat Evento de negocio, nao tem horario fixo
Gerar contrato sob demanda quando gerente pedir Skill Manual So faz sentido quando alguem solicita
Fazer backup das configuracoes Cron Rotina diaria, horario fixo
Alertar quando sistema detectar erro Heartbeat Evento critico, reacao em tempo real
Calcular comissoes quando vendedor pedir Skill Manual Sob demanda, gatilho humano

Comparacao de Custo: Tokens e Recursos

Cada mecanismo tem um perfil de custo diferente. Entender isso evita surpresas na fatura:

Aspecto Skill Manual Cron Heartbeat
Custo quando ocioso Zero — so consome quando chamado Zero entre execucoes Consome continuamente (verificacoes)
Previsibilidade Imprevisivel (depende do usuario) Alta (voce sabe exatamente quando roda) Media (verificacoes fixas, acao variavel)
Custo mensal tipico Baixo a medio Baixo e previsivel Medio a alto (depende do intervalo)
Escala Proporcional ao uso Fixo independente do tamanho Cresce com numero de monitoramentos
Heartbeat e o Mais Caro Quando Mal Configurado

Um heartbeat verificando a cada 1 minuto faz 43.200 checks por mes. Se cada check consome tokens (mesmo poucos), o custo acumula. Use heartbeats so para eventos que realmente precisam de reacao imediata. Para o resto, cron resolve com custo muito menor.

Combinando os Tres: Operacao Completa

O verdadeiro poder aparece quando voce combina os tres mecanismos para cobrir toda a operacao do negocio:

⏰

Cron

Processos recorrentes: relatorios, cobrancas, backups, limpeza, KPIs

⚡

Heartbeat

Reacao a eventos: estoque baixo, pagamento atrasado, erro detectado

👋

Skill Manual

Sob demanda: contratos, calculos, consultas, relatorios especificos

Exemplo Real: E-commerce Completo

Um e-commerce usando os tres juntos:

  • Cron (0 8 * * 1): Gera relatorio semanal de vendas com comparativo
  • Cron (0 3 * * *): Backup diario de configuracoes e dados criticos
  • Cron (0 9 5 * *): Processa cobrancas de inadimplentes do mes
  • Heartbeat (5 min): Monitora estoque — se abaixo do minimo, gera pedido de reposicao
  • Heartbeat (1 min): Monitora erros do sistema — se detectar, alerta equipe + cria ticket
  • Skill Manual: Gerente pede "gerar contrato pro cliente X" → agente gera e envia
  • Skill Manual: Vendedor pede "calcular minhas comissoes" → agente calcula e apresenta

Resultado: a operacao roda no piloto automatico. Relatorios chegam sem pedir. Estoque nunca falta. Cobrancas saem no dia certo. Erros sao detectados em minutos. E quando alguem precisa de algo especifico, o agente executa sob demanda.

Exemplo Real: Clinica de Saude

  • Cron (0 17 * * 5): Resumo semanal de atendimentos e faturamento
  • Cron (0 7 * * 1-5): Lista de pacientes do dia com historico resumido
  • Heartbeat (30 min): Detecta agenda vazia amanha → dispara campanha de last-minute
  • Heartbeat (15 min): Detecta pagamento atrasado → envia cobranca automatica
  • Skill Manual: Recepcionista pede "reagendar paciente Maria" → agente reagenda e notifica
A Combinacao Matadora

Cron gera relatorio diario + Heartbeat alerta anomalias + Skill Manual gera sob demanda. Cada um cobre um angulo. Juntos, eliminam 90% do trabalho operacional repetitivo.

Fluxograma de Decisao Rapida

Use este guia rapido para decidir em 10 segundos:

Pergunta Se SIM
Tem horario fixo pra rodar? Cron
Depende de algo acontecer no sistema? Heartbeat
So faz sentido quando alguem pede? Skill Manual
Precisa de reacao em menos de 5 min? Heartbeat
Pode esperar ate o proximo horario agendado? Cron
E uma consulta ou geracao pontual? Skill Manual
