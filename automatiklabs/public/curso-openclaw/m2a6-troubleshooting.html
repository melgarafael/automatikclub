Troubleshooting: Os 5 Erros Mais Comuns

15 min de leitura Nivel: Referencia

Esta aula e um guia de referencia. Nao precisa ler tudo agora — mas quando algo der errado (e vai dar), volte aqui. Estes sao os 5 erros mais comuns que alunos encontram durante a instalacao do agente executor e como resolve-los.

Dica

Salve esta pagina nos favoritos — voce vai precisar dela mais de uma vez. Problemas tecnicos fazem parte do processo, e a diferenca entre quem desiste e quem avanca e saber como resolver.

Erro 1: ECONNREFUSED

connect ECONNREFUSED 127.0.0.1:3000

O servico nao esta rodando ou nao esta escutando na porta correta

Quando acontece: Voce tenta enviar uma tarefa com curl, mas recebe "Connection refused". Isso significa que nao tem nada escutando na porta 3000.

# O erro aparece assim: curl: (7) Failed to connect to localhost port 3000: Connection refused

Como resolver:

# 1. Verifique se o processo esta rodando pm2 list # Se usa PM2 ps aux | grep node # Procura processos Node.js # 2. Reinicie o agente cd /home/openclaw/openclaw npm run start # 3. Verifique se a porta esta em uso sudo lsof -i :3000 # 4. Se outra coisa esta usando a porta, mate o processo sudo kill -9 $(sudo lsof -t -i:3000) npm run start

Erro 2: 401 Unauthorized

Error: Request failed with status code 401

Problemas com a conexao do ChatGPT Plus

Quando acontece: O agente inicia, mas quando tenta executar uma tarefa, a conexao com o ChatGPT falha. Sua assinatura Plus pode estar inativa, as credenciais incorretas ou a sessao expirada.

# O erro aparece assim nos logs: [OpenClaw] ChatGPT Connection Error: 401 Unauthorized [OpenClaw] Message: Authentication failed

Como resolver:

# 1. Verifique se sua assinatura ChatGPT Plus esta ativa # Acesse chat.openai.com > Settings > Subscription # 2. Reconecte sua conta no painel do OpenClaw # Va em Configuracoes > LLM > Reconectar # 3. Faca login novamente com email e senha do ChatGPT # 4. Teste a conexao: openclaw test-llm

Erro 3: ENOMEM

FATAL ERROR: CALL_AND_RETRY_LAST Allocation failed - JavaScript heap out of memory

A VPS ficou sem memoria RAM

Quando acontece: Geralmente em VPS com apenas 1-2 GB de RAM, especialmente quando o npm install esta rodando ou o agente executa muitas tarefas simultaneas.

# O erro aparece assim: FATAL ERROR: Reached heap limit Allocation failed - JavaScript heap out of memory

Como resolver:

# 1. Verifique a memoria disponivel free -h # 2. Criar um arquivo de swap (memoria virtual) sudo fallocate -l 2G /swapfile sudo chmod 600 /swapfile sudo mkswap /swapfile sudo swapon /swapfile # 3. Tornar permanente (sobrevive reboot) echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab # 4. Aumentar o limite de memoria do Node.js export NODE_OPTIONS="--max-old-space-size=1024" npm run start # 5. Se persistir, considere upgrade da VPS para 4 GB

Erro 4: ETIMEDOUT

Error: connect ETIMEDOUT

Timeout de rede — firewall ou DNS bloqueando a conexao

Quando acontece: O agente tenta acessar a API da OpenAI (ou qualquer servico externo) mas a requisicao nunca chega. Geralmente e o firewall da VPS bloqueando conexoes de saida, ou problemas de DNS.

# O erro aparece assim: [OpenClaw] Error: connect ETIMEDOUT 104.18.7.192:443 [OpenClaw] Unable to reach OpenAI API

Como resolver:

# 1. Teste se o servidor tem acesso a internet ping -c 3 google.com # 2. Teste acesso direto a API da OpenAI curl -I https://api.openai.com # 3. Se nao funcionar, verifique o DNS cat /etc/resolv.conf # Deve conter nameserver 8.8.8.8 ou similar # 4. Configurar DNS do Google echo "nameserver 8.8.8.8" | sudo tee /etc/resolv.conf echo "nameserver 8.8.4.4" | sudo tee -a /etc/resolv.conf # 5. Verifique se o firewall nao bloqueia conexoes de saida sudo ufw status sudo ufw default allow outgoing

Erro 5: Module not found

Error: Cannot find module 'express'

Dependencias faltando — npm install incompleto

Quando acontece: O npm install nao terminou corretamente, ou voce esta rodando o projeto de um diretorio errado. Pode acontecer com qualquer modulo (express, dotenv, openai, etc.).

# O erro aparece assim: Error: Cannot find module 'express' Require stack: - /home/openclaw/openclaw/src/index.js

Como resolver:

# 1. Certifique-se de estar na pasta correta cd /home/openclaw/openclaw ls package.json # Deve existir # 2. Limpe o cache e reinstale rm -rf node_modules rm package-lock.json npm cache clean --force npm install # 3. Se der erro de dependencia npm install --legacy-peer-deps # 4. Verifique que o Node.js esta atualizado node --version # Precisa ser v18+ # 5. Se o Node estiver desatualizado curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash - sudo apt install -y nodejs
Atencao

Se nenhuma solucao acima funcionar, verifique se sua VPS tem os requisitos minimos: 2 GB de RAM, Ubuntu 22.04+, e pelo menos 10 GB de disco livre. VPS muito pequenas podem causar problemas intermitentes dificeis de diagnosticar.

Comando de Diagnostico Universal

Quando nada parece funcionar, rode este script que verifica tudo de uma vez. Copie e cole no terminal:

#!/bin/bash # Script de diagnostico universal do OpenClaw echo "================================" echo "OpenClaw - Diagnostico Completo" echo "================================" echo "" echo "[1/8] Sistema Operacional:" lsb_release -d 2>/dev/null || cat /etc/os-release | head -1 echo "[2/8] Memoria:" free -h | grep Mem echo "[3/8] Disco:" df -h / | tail -1 echo "[4/8] Node.js:" node --version 2>/dev/null || echo "NAO INSTALADO" echo "[5/8] npm:" npm --version 2>/dev/null || echo "NAO INSTALADO" echo "[6/8] Porta 3000:" sudo lsof -i :3000 2>/dev/null || echo "Nenhum servico na porta 3000" echo "[7/8] Conectividade OpenAI:" curl -s -o /dev/null -w "%{http_code}" https://api.openai.com 2>/dev/null || echo "SEM ACESSO" echo "[8/8] Arquivo .env:" test -f .env && echo "Existe" || echo "NAO ENCONTRADO" echo "" echo "================================" echo "Diagnostico completo." echo "================================"

Copie a saida desse script e compartilhe no grupo de suporte caso precise de ajuda — com essas informacoes, conseguimos diagnosticar qualquer problema rapidamente.
