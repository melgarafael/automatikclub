Modulo 2 · Aula 4

Seu Primeiro Teste

15 min de leitura Nivel: Iniciante

OpenClaw instalado, IA conectada — agora e a hora da verdade. Nesta aula voce vai ligar o agente e pedir que ele execute sua primeira tarefa. Esse e o momento mais satisfatorio do curso: ver o agente realmente fazendo algo por voce.

Iniciando o Agente

Conecte no seu servidor via SSH e, dentro da pasta do OpenClaw, inicie o agente:

# Certifique-se de estar na pasta do projeto cd /root/openclaw # Inicie o agente npm run start # Saida esperada: # [OpenClaw] Starting agent... # [OpenClaw] Loading configuration... # [OpenClaw] Connecting to OpenAI API... # [OpenClaw] Agent is running on http://localhost:3000 # [OpenClaw] Ready to receive tasks ✓

O agente agora esta escutando na porta 3000. Deixe esse terminal aberto e abra uma nova aba/janela do terminal para os proximos passos.

Enviando sua Primeira Tarefa

Em uma nova janela de terminal (conectada ao mesmo servidor via SSH), envie uma tarefa de teste usando curl. Perceba: voce nao esta "conversando" com o agente — voce esta delegando uma tarefa para ele executar:

curl -X POST http://localhost:3000/api/task \ -H "Content-Type: application/json" \ -d '{"task": "Gerar um resumo das informacoes do sistema operacional deste servidor"}'

O Que Esperar

Se tudo estiver configurado corretamente, voce recebera uma resposta JSON mostrando o resultado da execucao:

{ "status": "completed", "task": "Gerar um resumo das informacoes do sistema operacional deste servidor", "result": "Sistema: Ubuntu 22.04 LTS | RAM: 4GB (2.1GB livre) | Disco: 100GB SSD (78GB livre) | CPU: 4 vCPUs | Uptime: 2h 34m", "model": "gpt-4o-mini", "execution_ms": 1847, "tokens_used": 152 }

Entendendo cada campo da resposta:

  • status — "completed" indica que a tarefa foi executada com sucesso
  • task — a tarefa que voce delegou ao agente
  • result — o resultado concreto da execucao (dados, relatorio, confirmacao)
  • model — qual modelo da OpenAI foi usado para o raciocinio
  • execution_ms — tempo total de execucao em milissegundos (abaixo de 3000 e bom)
  • tokens_used — quantos tokens foram consumidos (afeta o custo)

Testando Diferentes Tipos de Tarefa

Agora teste com diferentes tipos de tarefas para ver o agente executando processos reais:

1

Tarefa de analise de dados

Peca ao agente para processar e resumir informacoes — como faria com um relatorio de vendas ou inventario.

curl -X POST http://localhost:3000/api/task \ -H "Content-Type: application/json" \ -d '{"task": "Analisar o uso de disco do servidor e listar os 5 maiores diretorios"}'
2

Tarefa de geracao de conteudo

O agente pode gerar relatorios, emails e documentos estruturados sob demanda.

curl -X POST http://localhost:3000/api/task \ -H "Content-Type: application/json" \ -d '{"task": "Gerar um relatorio de status do servidor em formato JSON com: uptime, uso de memoria, uso de disco e processos ativos"}'
3

Tarefa de processamento complexo

Teste com uma tarefa que exige multiplos passos — o agente deve decompor e executar sequencialmente.

curl -X POST http://localhost:3000/api/task \ -H "Content-Type: application/json" \ -d '{"task": "Verificar se o servico OpenClaw esta saudavel: checar uso de CPU, memoria disponivel e conectividade com a API da OpenAI. Retornar um diagnostico com status OK ou ALERTA para cada item."}'
Dica

Nao se preocupe se os resultados ainda forem limitados — o agente ainda nao foi configurado com acesso aos sistemas do seu negocio. Isso e assunto do Modulo 3. O importante agora e confirmar que ele recebe a tarefa, processa e entrega um resultado.

Troubleshooting Rapido

Se algo deu errado, consulte esta tabela de problemas comuns:

Sintoma Causa Provavel Solucao
Timeout (sem resposta) Agente nao esta rodando Verifique se npm run start esta ativo no outro terminal
Erro 401 Unauthorized Conexao ChatGPT Plus inativa Reconecte sua conta em Configuracoes > LLM (veja aula M2A3)
ECONNREFUSED Servico nao esta escutando na porta Reinicie com npm run start e verifique a porta 3000
Resultado vazio ou incompleto Modelo nao configurado ou tarefa ambigua Verifique OPENAI_MODEL no .env (use gpt-4o-mini) e reformule a tarefa com mais detalhes
Execucao lenta (>10s) Tarefa complexa ou VPS lenta Tarefas com muitos passos levam mais tempo — normal. Se persistir, considere upgrade da VPS
Parabens!

Se recebeu resultado do agente nos tres cenarios, seu OpenClaw esta 100% operacional! Voce ja tem um agente executor de IA rodando no seu proprio servidor — capaz de receber tarefas e entregar resultados. A partir daqui, so melhora.
