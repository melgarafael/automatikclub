Instalando o Starter Kit

10 min de leitura Nivel: Iniciante

O Starter Kit e o ponto de partida para transformar seu OpenClaw generico em um agente executor de processos. Ele traz todos os arquivos e estruturas que voce precisa para configurar o papel operacional, os processos, as permissoes e muito mais.

O Que Vem no Kit

🧬

Soul File

Define o papel operacional do agente — que tipo de processos ele executa no seu negocio

📋

Agents.md

Instrucoes de processos — lista de tarefas, regras operacionais e limites de execucao

🔐

User Config

Define quem pode delegar tarefas ao agente e com qual nivel de autonomia

📄

Templates

Modelos prontos de processos, relatorios e configuracoes operacionais

Instalacao

Com o OpenClaw ja instalado na sua VPS (Modulo 2), rode o seguinte comando:

# Navegue ate a pasta do OpenClaw cd ~/openclaw # Instale o Starter Kit npm run install-starter-kit

O comando vai criar automaticamente toda a estrutura de pastas e arquivos base que voce vai configurar nas proximas aulas.

Estrutura de Pastas

Apos a instalacao, seu projeto tera a seguinte estrutura:

openclaw/ ├── soul/ │ └── soul.md ← Papel operacional ├── agents/ │ └── agents.md ← Processos e regras ├── config/ │ ├── users.json ← Quem delega tarefas │ └── settings.json ← Configuracoes ├── skills/ │ └── (skills operacionais) ├── memory/ │ └── (contexto operacional) └── integrations/ └── (sistemas conectados)
Dica

Nao edite nada ainda — vamos configurar cada arquivo nas proximas aulas. Por enquanto, apenas confirme que a estrutura foi criada corretamente.

Checklist da Aula

  • Starter Kit instalado — comando executado sem erros
  • Estrutura de pastas verificada — todas as pastas existem
  • Nenhum erro no terminal — instalacao limpa
