Conectando ao Telegram

15 min de leituraNivel: Intermediario

Telegram e o canal operacional mais poderoso para agentes OpenClaw — suporta grupos, topicos e bots nativos. Voce envia comandos, o agente executa e devolve resultados. Gratuito, sem limites de mensagens, e com uma API robusta para integracao.

Criando o Bot

1

Abra o @BotFather no Telegram

Procure por @BotFather no Telegram e inicie uma conversa. Ele e o bot oficial do Telegram para criar e gerenciar bots.

2

Envie /newbot

Digite o comando /newbot e siga as instrucoes. O BotFather vai pedir um nome e um username para o seu bot.

3

Escolha nome e username

O nome e o que aparece na conversa (ex: "Operador Financeiro X"). O username precisa terminar em "bot" (ex: @financeiro_x_bot).

4

Copie o token gerado

O BotFather vai gerar um token no formato 123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11. Copie e guarde em lugar seguro.

Criando o Grupo Operacional

1

Crie um grupo no Telegram

Abra o Telegram, toque em "Novo Grupo" e de um nome (ex: "Operacoes Empresa X").

2

Adicione o bot como admin

Adicione o bot que voce criou ao grupo e promova para administrador. Ele precisa de permissao para ler comandos e enviar resultados.

3

Ative Topicos (Topics)

Nas configuracoes do grupo, ative Topicos. Isso permite organizar os canais operacionais dentro do mesmo grupo.

4

Crie topicos: Tarefas, Relatorios, Alertas, Logs

Tarefas para enviar comandos ao agente. Relatorios para receber outputs gerados. Alertas para notificacoes automaticas. Logs para registro de operacoes executadas.

Conectando ao OpenClaw

# No arquivo .env, adicione: TELEGRAM_TOKEN=seu_token_aqui TELEGRAM_GROUP_ID=-100xxxxxxxxxx # Ative a integracao: npm run connect telegram

Testando

Envie um comando no topico Tarefas e veja se o agente executa e devolve o resultado:

# Teste rapido via terminal: npm run test-connection telegram # Resposta esperada: ✓ Telegram conectado com sucesso ✓ Bot operacional no grupo ✓ Topicos detectados: Tarefas, Relatorios, Alertas, Logs

Agora teste um comando real no topico Tarefas:

# Envie no topico Tarefas: /relatorio vendas hoje # O agente processa e envia no topico Relatorios: 📊 Relatorio de Vendas — 25/05/2026 Total: R$12.450,00 | Pedidos: 23 | Ticket medio: R$541,30 Top produto: Kit Premium (8 un)
Sucesso

Se o agente executou o comando e entregou o resultado, parabens! Seu agente agora tem um canal operacional. Voce delega tarefas pelo Telegram e recebe os resultados automaticamente.

Dica

Topicos no Telegram sao perfeitos para separar fluxos operacionais. O topico Tarefas recebe comandos, Relatorios recebe outputs, Alertas notifica anomalias e Logs registra tudo que foi executado.

Atencao

Nunca compartilhe o token do bot publicamente — e como uma senha. Se vazar, qualquer pessoa pode enviar comandos ao seu agente. Revogue imediatamente pelo @BotFather se isso acontecer.

Checklist da Aula

  • Bot criado no BotFather — nome e username definidos
  • Token copiado — armazenado no .env
  • Grupo operacional criado — com nome profissional
  • Bot adicionado como admin — permissoes configuradas
  • Topicos ativados — Tarefas, Relatorios, Alertas, Logs
  • Comando testado — agente executou e devolveu resultado
