💡 Regra prática

Comece com uma integração, teste bem, e só depois adicione outra. Cada integração nova é uma peça móvel — quanto mais peças, mais chances de algo quebrar.

Como as integrações funcionam

Toda integração segue o mesmo padrão básico:

  1. Autenticação — Você autoriza o OpenClaw a acessar o serviço (OAuth, API key, ou token)
  2. Configuração — Define quais permissões o agente tem (só leitura? leitura e escrita?)
  3. Mapeamento — Conecta funções específicas do agente às ações do serviço
  4. Teste — Verifica se tudo funciona antes de colocar em produção
